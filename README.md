## 🚀 Projects

### 📱 Android / Mobile

**🧮 The Calculator** — *Smart & Self-Aware*
> A calculator app that updates itself. Bypasses Play Store dependency entirely by polling the **GitHub Releases API** for new versions and downloading updates in the background via Kotlin Coroutines. Calculation history persists across sessions using `SharedPreferences`.
`Kotlin` `XML` `GitHub API` `Coroutines` `SharedPreferences`

---

**🏭 Millmate** — *Industrial Management*
> Mobile-first ERP for factory floors. Tracks inventory and machine usage in real time, streamlining workflows for on-the-go industrial managers. Built around operational efficiency where every second counts.
`Kotlin` `Firebase` `Real-time DB`

---
